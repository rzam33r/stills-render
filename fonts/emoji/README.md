Emoji pictures: Google's Noto emoji (Apache License 2.0), as packed into one
sheet by the npm package emoji-datasource-google 15.1.2 (MIT, LICENSE file
here). Each emoji is 64 x 64 at (x * 66 + 1, y * 66 + 1); google-64.json maps
each emoji's code points (e.g. "1F480") to its [x, y]. Used for emoji in a
short film's hook line and subtitles.
